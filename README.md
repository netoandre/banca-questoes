# Banca.

Preciso de um aplicativo que gerencia provas para um professor. O professor poderá cadastrar suas turmas em cada semestre, cadastrar as provas (1 avaliação, 2 avaliação, 2 chamada, etc). A ideia é que tenha um espaço para colar questões e o app identifique questão e alternativas e o gabarito separado. Deve ser possível selecionar questões para montar uma prova. O app deve, ao gerar a prova, embaralhar as alternativas e a ordem das questões e deve armazenar o gabarito da prova para posterior correção. Disponibilizar opção para copiar questões da prova de uma maneira formatada que facilite colar no word com boa formatação. Permitir inclusão de questões subjetivas também. Possibilidade de incluir peso de cada questão também. Mas de uma forma que facilite a correção (por exemplo, mantendo próximas as questões de mesmo peso na ordem da prova). Também é bom uma funcionalidade para gerar nova prova embaralhando as questões, por exemplo prova A e prova B. O app deve facilitar a edição de enunciados e questões. Também gostaria de poder gerar questões adaptadas com base nas questões já cadastradas, isto é , questões com somente 4 alternativas, mais diretas, com menos contexto e sem pegadinhas, para gerar provas para pessoas neurodivergentes ou com dificuldades. Se for possível permitir o uso de IA, seria legal. Incluir também tags para facilitar a busca por questões para criar a prova
